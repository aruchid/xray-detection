## 备选：CXR-AD 工业零部件异常检测

[作者论文](https://arxiv.org/abs/2505.03412)报告 5 类工业零部件，653 张正常样本、561 张缺陷样本，并有像素级掩膜。这种标注适合定位评测。

当前仅核实论文描述；尚未核实可用的作者下载地址和数据许可，因此不把它列为可直接下载的数据源，也不以论文公开等同于数据可以商业使用。

## 现有算法的关键缺口

`src/prototype.py::process(image, reference)`要求已配准、同尺寸的检测灰度图与正常参考图。公开数据中存在正常样本，并不意味着任意正常图都能直接相减；零件姿态、曝光和厚度变化会产生伪异常。

禁止把待测图自身或其平滑版本当正常参考，再将输出解释成真实缺陷检测通过。若用真实背景添加人工缺陷，必须单独标记为半合成验证。

## 实施步骤与验收

1. 下载 Castings 到被 Git 忽略的 `data/`，记录来源、日期、文件名、SHA256；读取原始位深和标注格式。
2. 建立样本清单：零件/系列、正常或异常标签、缺陷标注、参考图来源、尺寸与曝光信息。检查是否满足成对参考要求。
3. 若存在可用参考，先配准和曝光校正；若不存在，记录现有算法不适用，另建正常样本建模基线。不同方法分别报告。
4. 按零件或采集系列拆分训练、验证、测试集，避免相邻图或同件不同视角泄漏。阈值仅在验证集上选择。
5. 有像素掩膜时报告像素指标；只有框标注时按框评测，不能把框内部全当真实缺陷像素。报告正常误报、异常召回、耗时和失败例。
6. 更新 `docs/VALIDATION.md`，分别保留合成回归结果、公开真实数据结果、现场验收结果。

## 现场仍需的数据

- 相同零件与视角的正常参考图及待测图，保留原始灰度/位深。
- 正常样本、典型缺陷、困难负样本；缺陷位置、类型及质检判定。
- 设备、曝光、像素尺寸、批次和采集时间等可追溯信息。
- 可使用与可公开的范围，以及现场接受的漏检、误报与处理时间。

公开数据可以推进导入、配准和算法比较；最终现场泛化仍需用户设备上的真实数据验证。
